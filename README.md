# 07-revflow（冲流台）

冲流台 — 正向与冲正流水净额归并：正向装载 → 冲正关联入账 → 净额归并落余额 → 未平/超额隔离 → 流水净额与余额互证。

**不是** 多源 Feed 归并，**不是** 作业依赖编排，**不是** CDC 变更流，**不是** 质检签发，**不是** 数仓分层建设，**不是** 交班过户。  
**也不是** 收银/退款 CRUD 后台、电商订单、报表 CSV 看板——主链是**流水管道与净额状态**，不是业务单据编辑台。

## 主链

账户登记 → 装载正向流水 → 装载冲正并关联原单 → （可选）声明冲正捆扎 → 跑净额归并（已配平落余额，未平/超额进隔离）→ 互证报告核对「流水净额 vs 账户余额」

## 多腿冲正捆扎（multi_leg_net）

一批冲正可声明同一**捆扎键**，作为同一配平单元「全成或全进未平」：

- **落库形态**：独立捆扎表 `reversal_bundles`（捆状态：待归捆/整捆已归并/整捆已隔离）+ `reversal_bundle_members`（成员冲正键，一笔至多属一捆）；隔离项与归并运行冗余 `bundle_key`，落库即可区分捆扎集合与散笔，不依赖请求体数组。
- **失败闭**：成员状态 + 余额 + 隔离 + 捆状态在同一 SQLite 事务内提交。同捆全部冲正可解析原单、账户一致且各自不超额，整捆才进「已归并」并改余额；任一腿不满足则整捆进未平隔离（好腿标注「连带隔离」），正式余额分毫不动；事务中途异常整体回滚。
- **按捆报告**：归并运行记录成功捆数/失败捆数/成员笔数与运行范围（散笔/按捆），互证报告按捆解释并与捆扎记录、流水、隔离、余额同源。

| 接口 | 说明 |
| --- | --- |
| `POST /api/reversal-bundles` | 声明捆扎 `{bundle_key, entry_keys[]}` |
| `GET /api/reversal-bundles` / `/{bundle_key}` | 捆状态与成员 |
| `POST /api/reversal-bundles/{bundle_key}/settle` | 按捆归并（整捆成败） |
| `GET /api/quarantine?bundle_key=` | 未平隔离按捆扎键过滤 |
| `POST /api/settle-runs` | 全量归并：散笔逐笔 + 待归捆按捆 |

## 界面约定

页面文案全部中文；入口：总览 / 账户 / 正向流水 / 冲正流水 / 归并台 / 未平隔离 / 净额互证。  
视觉：**左轨编号导航 + 右侧账册横线工作面**（Literata / JetBrains Mono，靛蓝强调）；**不是**交班台那种顶栏品牌+横向流程条。
